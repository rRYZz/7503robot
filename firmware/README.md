# ESP32 固件接入位置

此处预留给真实 micro-ROS 固件。当前没有烧录程序，也没有修改 ESP32。

队友接入时应提供源码、构建／烧录方式、引脚与轮序、消息接口、速度看门狗和升降停止／保持说明。任务框架不会把模拟程序作为真实控制器使用。

树莓派端已经提供 `velocity_json_bridge`，由实机启动入口自动运行。底盘通信程序订阅 `/team2/robot/base/cmd_vel_json`（`std_msgs/msg/String`），将 `data` 中的完整 JSON 发给 ESP32：

```json
{"linear":{"x":0.10,"y":0.0,"z":0.0},"angular":{"x":0.0,"y":0.0,"z":0.0}}
```

`linear.x/y` 为车体前/左速度（m/s），`angular.z` 为逆时针转速（rad/s）；其余字段为零。ESP32 做麦轮运动学解算与四轮编码器速度闭环。转换器不打开串口；若采用串口，可约定 UTF-8 JSON 加换行符 `\n` 分帧，由通信程序和固件共同实现。ESP32 必须在新命令断流时独立停车。

输入速度正常时默认20 Hz，转换器收到一条即输出一条；默认0.3秒没有新 Twist、非法输入、尚无输入或正常退出时输出零速。转换器不代替 MCU 看门狗、不代替升降控制，也不生成实测反馈。完整接口见 [导航接入与部署](../docs/导航接入与部署.md)。
